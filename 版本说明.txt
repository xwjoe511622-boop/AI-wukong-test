AI 悟空 · 体验版

本包默认以【体验版】运行（由根目录的 .env 文件指定，请勿删除）。
与正式版只有三点不同：
- 赠送 1000 蟠桃和 10000 USDT
- 七个阶段全部开放
- 周期统一缩短为 1 天（正式版为 1 / 3 / 5 / 8 / 12 / 15 / 20 天）
成长比例、蟠桃消耗、召唤时间、同行与部族奖励比例与正式版相同。

运行：
  pnpm install        （或 npm install）
  npm run dev         开发预览，默认 http://localhost:3000
  npm run build       打包
  npm test            运行测试

说明：体验版余额为体验数据，不可提现；未接入真实充值、打款与匹配后台。
