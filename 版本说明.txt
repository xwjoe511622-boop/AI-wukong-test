AI 悟空 · 体验版

本包默认以【体验版】运行（由根目录的 .env 文件指定，请勿删除）。
体验版用来快速熟悉玩法：
- 赠送 1000 蟠桃和 10000 USDT
- 七个阶段全部开放
- 时间加速：正式版的整个修炼周期（1 / 3 / 5 / 8 / 12 / 15 / 20 天）压缩为真实的 1 天，
  每只悟空只需点 1 次修炼，这一次扣满正式周期的全部修炼蟠桃、算整个周期的修炼加成；
  正式版需要每天点一次，当天没点就没有当天的修炼加成，过后不能补
页面上的周期、每日修炼、消耗等一律按正式版数值显示，不出现「体验版 / 正式版」字样；
只有顶部每 30 秒浮出一次的小提示会说明当前是体验版。
修炼范围、圆满加成、召唤时间、同行与部族奖励比例与正式版相同。

运行：
  pnpm install        （或 npm install）
  npm run dev         开发预览，默认 http://localhost:3000
  npm run build       打包
  npm test            运行测试

说明：体验版余额为体验数据，不可提现；未接入真实充值、支付结算与匹配后台。
